# Librerías de componentes UI

Yo me quedaria con [HeroUI](https://heroui.com/), que está pensado para Next.js.
La mayoría tienen un theme builder, así que son personalizables.
Os dejo por aquí otras opciones:

## HeroUI

- [HeroUI](https://heroui.com/)
- Componentes React sobre Tailwind, con theme builder, animaciones y accesibilidad, pensado para Next.js.

## daisyUI

- [daisyUI](https://daisyui.com)
- Añade nombres de clase semánticos a Tailwind CSS para construir interfaces sin JS y con theme builder.

## Flowbite

- [Flowbite](https://flowbite.com/)
- Biblioteca de componentes sobre Tailwind con elementos interactivos con JS propio. Tiene bindings para React.

## shadcn/ui

- [shadcn](https://ui.shadcn.com/)
- Código de componentes React que copias al proyecto. Más complejo, con soporte para Next.

## Bulma

- [Bulma](https://bulma.io/)
- CSS basado en Flexbox, con clases semánticas y sin dependencia de Node ni build obligatorio.

## Bootstrap

- Clásico pero poco flexible.
- [Bootstrap](https://getbootstrap.com/docs/5.3/getting-started/introduction/)
